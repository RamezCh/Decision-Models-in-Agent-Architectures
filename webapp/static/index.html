Two AI models that decide instead of write

Chatbots like ChatGPT write an answer word by word. Jev and CLM never write anything: you give them a situation and a multiple-choice question, and they return every option's probability in one go, usually in well under a second. The cube race sends the exact same question to both models, so you can compare answer, confidence and speed side by side. The scam check and the guard game run on CLM-8B, the open model you can host yourself.

Cube race

Beat the guard

Trick the vault bot into revealing its password. CLM-8B and a plain keyword filter try to stop you.

Times include the network: Jev answers from the US West Coast, CLM from wherever you run it. Hover over the dots in the top bar to see each model's connection status.
