Models that decide instead of write

A chatbot writes its answer word by word. A System One model never writes: you give it a situation and a few questions with fixed answers, and in one pass it returns how likely each answer is. Three demos show what that's good for, where it breaks, and how it works together with a chatbot.

System 2 · chat LLM
"I was charged twice…"→ Thecustomerwascharged…→ text you still have to read and check
thinks step by step · seconds · can write anything
System 1 · decision model
situation + questions→ one pass→ refund? 90% · team: billing 85%
~100 ms · only the answers you allowed · can still be wrong

The models

CLM-8BSystem 1

Open model from Stanford and NVIDIA. Matches the situation against the text of each possible answer. Runs on our own A100 on the BHT cluster.

BHT MediumSystem 2

Gemma 4 32B, a chat LLM on BHT's LUMIS. Plays Vaulty, reviews borderline messages for the guard and can race the cube, so you see a chatbot next to the decision model.

JevSystem 1

TypeSafe's hosted decision model, trained to give honest probabilities. Optional: it joins the comparisons when an API key is set.

How you ask matters

Paste a Berlin flat listing. CLM answers ten small yes/no questions; plain code weighs them into a risk you can explain question by question.

0.42 → 0.97AUC, same model: clear yes/no descriptions plus weights learned from 30 labelled listings

System 1 + System 2
